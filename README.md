## What projects are on here
- Teddy-Editor: A modeless text editor I wrote in C that I may add new features as I start using it more and more. The name "Teddy" was just the first thing that came to mind because it contains "ted" in the name which would stand for "text editor".
- ArchLinuxDotfiles: The name kind of gives it away. It's my arch linux configuration with an installation script, and it took a few months to build (finished 13th September 2026) but I can now say it is complete and will have less and less new features as I run out of ideas. Bug fixes will always be added constantly, however, because it is the config I actually use.
- Mesh-Shell: It's a simple shell I wrote in C that does one thing well, which is being a shell, not a full programming language and environment manager like bash. The name "Mesh" was the first thing that came to mind when I wanted to combine "m" from "minimal" and "sh" from "shell".

The testing environment (that uses Docker), however, is put on top of Alpine linux for simplicity reasons.
